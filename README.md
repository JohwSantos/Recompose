# Atividade Recompose

Atividade desenvolvida em Android Studio utilizando Jetpack Compose.

## Objetivo

Demonstrar o conceito de Recompose através de um TextField.

## Funcionamento

O usuário digita um texto no TextField.

Quando o valor é alterado, o estado da aplicação também é alterado. O Jetpack Compose identifica essa mudança e realiza a recomposição da interface.

## Tecnologias

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## Conceito demonstrado

O projeto demonstra o funcionamento de:

- remember
- mutableStateOf
- TextField
- onValueChange
- Recompose
